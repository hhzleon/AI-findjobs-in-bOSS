# 使用方法

1. **登录并启动主程序**
   - 运行 `main.py`，使用打开的浏览器登录 BOSS 直聘账号，并保持窗口打开（不要关闭）。
   - 选择合适的模式，等待爬取足够的职位。

2. **采集职位URL**
   - 运行 `build_job_url.py`，根据你的关键词、城市等采集职位详情页的URL，生成 `boss_job_url.csv` 文件。

3. **爬取职位详情**
   - 运行 `job_detail_crawler.py`，程序会自动读取 `boss_job_url.csv`，爬取每个职位的详细信息，并保存为 `job_details_with_text.csv`。

4. **整理为JSON格式**
   - 使用 `整理脚本`（如 `csv2json.py` 或相关脚本），将 `job_details_with_text.csv` 转换为结构化的 `job_details_simple.json`，方便后续分析和处理。

## 注意

本项目仅负责自动化采集职位信息和可视化分析，**不包含自动投递、消息通知等自动化流程**。要实现完整的自动化流程，请期待后续更新。目前版本需要配合 N8N 搭建和运行，后续会更新无需 N8N 的独立版本，敬请关注。
